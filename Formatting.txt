# دليل وقواعد التنسيق والنسخ المعتمدة (Formatting & Transcription Guidelines)

تم حفظ وتوثيق هذه القواعد للرجوع إليها في جميع مشاريع التفريغ والتنسيق (Non-Parsable / DTP / Transcription / Formatting):

---

## 1. وسوم التوثيق والرموز الخاصة (Tags & Placeholders)

| الوسم / Tag | الاستخدام والوصف |
| :--- | :--- |
| `[emblem:]` | لوجود شعارات رسمية (مثل صيدلية، مستشفى، شعار دولة أو هيئة حكومية). |
| `[redacted]` | كلام مش واضح أو مستخفي بورقة أو شخطبة أو محجوب عمداً. |
| `[PPD]` | Pre-Printed Document / Data. |
| `[CCI]` | Chamber of Commerce and Industry أو حسب سياق الوثيقة. |
| `[logo: xxxxxxxxxxx]` | لوجو موجود وبداخله كلام مكتوب، يُكتب الكلام مكان `xxxxxxxxxxx` بدون رسم أو إدراج صورة اللوجو. |
| `[signature]` | توقيع يدوي لشخص داخل المستند أو الصور. |
| `[initials]` | توقيع مصغر / تأشيرة بالأحرف الأولى (فورمة مصغرة). |
| `[stamp: xxxxxxxxxxx]` | أختام أو طوابع بريد، ويُفرغ النص المكتوب داخل الختم مكان `xxxxxxxxxxx`. |
| `[seal:]` | إذا كان الختم يحتوي على اسم الشخص أو الختم الرسمي للشخص (مثل ختم كاتب العدل). |
| `[electronic signature: xxxxxxxxxxx]` | توقيع إلكتروني صريح مع تفريغ بياناته إن وجدت. |
| `[e-signature]` | إمضاء إلكتروني عام، ولو بداخله نص يمكن استخراجه يُكتب. |
| `[digital signature]` | توقيع رقمي معتمد تقنياً. |
| `[illegible] xxxxxxxxxxx` | كتابة غير واضحة تماماً بسبب رداءة جودة الصفحة أو التصوير (مع كتابة ما يمكن تخمينه أو تركه فارغاً). |
| `[illegible section]` | مقطع أو فقرة كاملة غير ظاهرة أو غير مقروءة. |
| `[illegible line]` | سطر كامل غير مقروء أو غير ظاهر. |
| `[watermark: xxxxxxxxxx]` | علامة مائية؛ تُكتب عادة في الترويسة (Header) مع تفريغ النص المقروء منها. |
| `[icon]` | أي أيقونة أو رمز جرافيكي صغير. |
| `[cut off text] xxxxxx` | كلام مقطوع عند حافة الورقة؛ نكتب الحروف الظاهرة فقط مكان `xxxxxx`. |
| `[hw: xxxxxx]` | كلام مكتوب بخط اليد وليس رقمياً (digital)؛ ويوضع النص بتنسيق مائل (*Italic*). |
| `[barcode: xxxx]` | باركود؛ لا يتم رسمه، وإنما تُستخرج الأرقام أو الحروف التابعة له وتُكتب بجانبه. |
| `[QR code]` | رمز الاستجابة السريعة QR. |
| `[blank page in source]` | صفحة فارغة في ملف الـ PDF الأصلي. |
| `undefined` | عندما توجد مربعات أو حقول فارغة يُطلب ملؤها وتُركت فارغة. |
| `[handwritten text is indicated in italics]` | إذا كان الملف يحتوي على الكثير من النصوص المكتوبة بخط اليد، توضع هذه العبارة في الـ Header فقط. |

## 2. رموز ومحارف هامة (Symbols & Characters)

### رموز الشيك بوكس والقوائم (Checkboxes & Bullets)
- **مربع أسود (ممتلئ):** `■` (Alt + 9632 / U+25A0)
- **مربع فارغ:** `□` (Alt + 9633 / U+25A1)
- **دائرة سوداء (ممتلئة):** `●` (Alt + 9679 / U+25CF)
- **دائرة فارغة:** `○` (Alt + 9675 / U+25CB)
- **علامة الضرب / إشارة X:** `(×)` أو `×`

### علامات الترقيم والمحارف الخاصة
- خط عمودي: `|`
- وفقاً لـ / طبقا لـ (ألماني): `gemäß`
- رمز الفقرة / المادة القانونية: `§`
- رقم: `№`

### التوقيت والمناطق الزمنية
- `ET` / `EDT` / `EST` (توقيت أمريكا الشرقي - تُعامل بنفس المعيار)
- `CET` / `BST` / `GMT` (توقيت أوروبا / بريطانيا / غرينتش - تُعامل بنفس المعيار)

### مصطلحات ومقاييس طبية وعلمية
- اليقظة الدوائية: `pharmacovigilance`
- الوسط الحسابي والانحراف المعياري: `(x̄±s)`
- الحروف اليونانية:
  - ألفا: `α`
  - بيتا: `β`
  - جاما: `γ`
- حرف الهاء بصورته الممتدة: `هـ`
- الكسور الشائعة:
  - ربع: `¼`
  - نصف: `½`
  - ثلث: `⅓`
  - ثلاثة أرباع: `¾`

## 3. تنظيم مجلد العمل ودورة معالجة الملفات (Project Structure & File Workflow)

1. مجلد المدخلات (`input/`): توضع ملفات الـ PDF الجديدة المطلوب معالجتها.
2. مجلد المخرجات (`output/`): تحفظ جميع ملفات الـ Word المنجزة (.docx).
3. مجلد الملفات المنتهية (`finished/`): ينقل ملف الـ PDF الأصلي تلقائياً بعد اجتياز فحص الجودة.
4. السكربتات البرمجية (`scripts/`).
5. ملفات الفحص والاختبار (`tests/`).
