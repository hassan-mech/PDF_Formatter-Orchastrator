# Tag Emitter Skill Summary
- Appendix A: Canonical tags ([stamp:], [hw:], [signature], [logo:], etc.). Verbatim, no paraphrasing.
- Appendix B: Canonical symbols (Unicode glyphs).
- Rules: Always square brackets, payload format [tag: payload], never translate tag names, no nested tags.
